TV Renamer

Plex-friendly names from TheTVDB

1Connect to TheTVDB

TV Renamer looks up episode titles on TheTVDB. Paste your API key once and it's remembered on this Mac. Don't have one? Get a key here.

1Choose a show's folder

Pick the folder that holds one show (for example Ray Donovan). Nothing changes until you review and press Rename.

Naming options

Undo a previous run

Each run saves a small log in the folder it worked on. Undo puts every file and folder from that run back to its old name.
