# ASK Wellness Center: Homepage Redesign Mockup

A proposed new homepage for [askwellnesscenter.com](https://askwellnesscenter.com) (Valerie Perry, LCSW, Bentonville, AR).

Open `index.html` in any browser to preview. It is a single static page with no build step.

## What's in it

- **Brand colors sampled from the ASK sign:** red `#C84852`, navy `#2F3863`, blue `#3C5280`, and green `#2F8F69`, plus a warm gold accent for the seniors card.
- **Her real content:** the bio, services by age group, FAQ, hours, address, and the "ASK / SEEK / KNOCK" line, all pulled from the current site and tightened.
- **Her real photos:** the headshot and five office photos from the current site, resized for the web.
- **Built to convert:** a call button in the header, tap-to-call and request buttons fixed to the bottom of phone screens, a three-step "Getting Started" section, insurance stated up front, and a short request form.
- **Built to be found:** a real page title and meta description that name Bentonville, LocalBusiness schema markup (address, hours, phone), and mobile-responsive layout.
